# Project Learnings & Memory (`.agents/learnings/`)

Thư mục này lưu trữ bộ nhớ dự án, bài học kinh nghiệm (Lessons Learned) và lịch sử khắc phục các sự cố phức tạp trong hệ sinh thái **CliniPortal**.

## 📌 Hướng dẫn Sử dụng
- Mỗi bài học mới có thể được lưu thành file `.md` trong thư mục này với định dạng tên `YYYY-MM-topic.md` hoặc theo tên phân hệ.
- **Khi nào thêm bài học mới?**:
  - Khi hoàn tất sửa một lỗi hệ thống hoặc bug vỡ layout phức tạp.
  - Khi áp dụng thành công một pattern/kiến trúc mới.
  - Khi sử dụng lệnh `/learn` từ người dùng.
- **AI Agent Requirement**: Trước khi xử lý các tác vụ refactor hoặc sửa lỗi hệ thống phức tạp, AI hãy tham khảo thư mục này để tránh lặp lại các sai lầm cũ.
