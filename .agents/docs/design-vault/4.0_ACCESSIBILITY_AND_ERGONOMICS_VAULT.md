## 2. Tương Phản Màu Sắc Quang Phổ (Contrast Ratio Matrix)

### A. Trên Nền Trắng / Nền Sáng (`--color-surface: #ffffff`)
- **Chữ chính (`--color-text: oklch(20% 0.03 240)`)**: Tương phản **$14.8:1$** (Vượt xa chuẩn AAA $7:1$).
- **Primary Action (`--color-primary: oklch(58% 0.18 225)`)**: Tương phản **$4.8:1$** trên nền trắng.
- **Cấp cứu Critical (`--clinical-critical: oklch(62% 0.22 25)`)**: Tương phản **$5.2:1$** trên nền trắng.

### B. Trên Nền Tối / Trực Đêm (`--color-bg: oklch(14% 0.02 240)`)
- **Chữ sáng (`--color-text: oklch(94% 0.01 240)`)**: Tương phản **$16.1:1$** (Siêu sắc nét, không mờ mắt).
- **Primary Dark Accent (`oklch(75% 0.16 225)`)**: Tương phản **$8.6:1$** trên nền đêm tối.
- **Critical Dark Alert (`oklch(75% 0.18 25)`)**: Tương phản **$8.1:1$** trên nền đêm tối.

## 3. Công Thái Học Thao Tác 1 Tay Trên Di Động (Thumb-Zone)

Khi bác sĩ đi buồng bệnh cầm điện thoại bằng 1 tay:
1. **Khu vực Thuận Tiện Nhất (Natural Thumb Arc - 1/3 Dưới Màn Hình)**:
   - Đặt thanh tìm kiếm nhanh, nút Mở Bedside Calculator, các nút Cấp cứu khẩn cấp.
2. **Khu vực Khó Với Tới (Stretch Zone - 1/3 Trên Màn Hình)**:
   - Đặt tiêu đề bài viết, nhãn breadcrumbs, thông tin ngày cập nhật.
3. **Kỹ Thuật Mở Rộng Vùng Bấm (Touch Expansion Padding)**:
   ```css
   /* Mở rộng vùng bấm vô hình cho các icon nhỏ */
   .clini-touch-expand {
     position: relative;
   }
   .clini-touch-expand::after {
     content: '';
     position: absolute;
     top: 50%;
     left: 50%;
     transform: translate(-50%, -50%);
     min-width: 44px;
     min-height: 44px;
     width: 100%;
     height: 100%;
   }
   ```

## 4. Quy Chuẩn Điều Hướng Bàn Phím (Keyboard Navigation)

### A. Phím Tắt Tiêu Chuẩn Trong CliniPortal
- `Tab` / `Shift + Tab`: Di chuyển tuần tự qua các nút bấm, ô nhập liệu và liên kết.
- `Enter` / `Space`: Kích hoạt nút bấm hoặc mở/đóng Superblock Accordion.
- `Escape`: Đóng ngay lập tức Bedside Drawer, Modal hoặc Popup đang mở.
- `Ctrl + K` (hoặc `/`): Tự động focus vào thanh tìm kiếm toàn cục.

### B. JavaScript Xử Lý Phím `Escape` An Toàn:
```javascript
document.addEventListener('keydown', function(event) {
  if (event.key === 'Escape') {
    const openDrawers = document.querySelectorAll('.clini-drawer-jaw.is-open');
    openDrawers.forEach(drawer => drawer.classList.remove('is-open'));
  }
});
```

## 5. Thiết Kế Chống Lóa & Bảo Vệ Mắt Trực Đêm (Night Shift Dark Mode)

1. **Tránh Đen Tuyệt Đối `#000000` Cho Nền Rộng**: Sử dụng nền đen pha sắc xanh phiến đá sâu `oklch(14% 0.02 240)` để tránh hiện tượng bóng ma quang học (OLED Smearing / Halation Effect) khi cuộn nhanh bài viết.
2. **Hạ Sắc Độ Của Ảnh Minh Họa Y Khoa**:
   ```css
   [data-theme="dark"] img:not([data-no-filter]) {
     filter: brightness(0.9) contrast(1.05);
   }
   ```
3. **Giảm Độ Chói Của Màu Đỏ Cấp Cứu**: Chuyển từ đỏ tươi ban ngày sang đỏ ngọc dịu mắt ban đêm (`oklch(75% 0.18 25)`) với nền làm mờ `alpha 0.15`.
