## 2. Hệ Thống Typography & Dynamic Line-Heights

### 📐 Công Thức Tính Phân Số Dynamic Line-Height
```css
/* Nhãn cực nhỏ (Badges/Tags): Dày dặn chống vỡ khung */
--text-xs:               clamp(0.72rem, 0.68rem + 0.2vw, 0.8rem);
--text-xs--line-height:  calc(1 / 0.75);      /* = 1.333 */

/* Bảng cận lâm sàng & Chỉ số xét nghiệm: */
--text-sm:               clamp(0.82rem, 0.78rem + 0.2vw, 0.9rem);
--text-sm--line-height:  calc(1.25 / 0.875); /* = 1.428 */

/* Bài đọc lâm sàng chính văn (Prose Standard): */
--text-base:             clamp(0.92rem, 0.88rem + 0.2vw, 1.02rem);
--text-base--line-height:calc(1.5 / 1);       /* = 1.500 */

/* Tiêu đề mục H3 / Card Title: */
--text-lg:               clamp(1.15rem, 1.05rem + 0.4vw, 1.35rem);
--text-lg--line-height:  calc(1.75 / 1.125); /* = 1.555 */

/* Tiêu đề chương H2: */
--text-2xl:              clamp(1.75rem, 1.5rem + 1.2vw, 2.3rem);
--text-2xl--line-height: calc(2 / 1.5);       /* = 1.333 */

/* Hero Banner Headline H1: */
--text-3xl:              clamp(2.2rem, 1.8rem + 1.8vw, 3rem);
--text-3xl--line-height: 1.15;
```
