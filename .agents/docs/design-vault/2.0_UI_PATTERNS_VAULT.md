## Pattern 1: Bento Grid Clinical Dashboard

Dùng cho: Trang chủ các phân hệ, Dashboard Tổng quan Cận lâm sàng, hoặc Bảng theo dõi Sinh hiệu.

```html
<div class="clini-bento-grid">
  <!-- Card Lớn: Biểu đồ Sinh hiệu & Trạng thái Tổng quan -->
  <div class="clini-card clini-card--elevated clini-bento--span-2">
    <div class="clini-bento-header">
      <span class="clini-badge clini-badge--critical clini-badge--pill">
        <span class="clini-pulse-dot"></span> Đang Theo Dõi Cấp Cứu
      </span>
      <span class="clini-text-muted">Cập nhật 2 phút trước</span>
    </div>
    <h3 class="clini-bento-title">Huyết Động Học & Khí Máu Động Mạch</h3>
    <div class="clini-kpi-grid">
      <div class="clini-kpi-item">
        <span class="clini-kpi-label">Huyết áp</span>
        <strong class="clini-kpi-value">85/50 <small>mmHg</small></strong>
      </div>
      <div class="clini-kpi-item">
        <span class="clini-kpi-label">Lactate</span>
        <strong class="clini-kpi-value clini-text-danger">4.2 <small>mmol/L</small></strong>
      </div>
    </div>
  </div>

  <!-- Card Nhỏ: Phím tắt Thang điểm nhanh -->
  <div class="clini-card clini-card--elevated">
    <h4 class="clini-card-title">Thang Điểm SOFA</h4>
```

## Pattern 2: Superblock 4-Tier Accordion

*Đúc kết từ freeCodeCamp:* Dùng cho cây danh mục phác đồ điều trị, kho hướng dẫn chẩn đoán, cây bệnh học.

```html
<div class="clini-accordion">
  <!-- Chapter Item -->
  <div class="clini-accordion-chapter">
    <div class="clini-chapter-header">
      <a href="./tim-mach-stemi.html" class="clini-chapter-title-btn">

        <span class="clini-chapter-name">Chương 1: Nhồi Máu Cơ Tim Cấp ST Chênh Lên</span>
      </a>

        <svg width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><path d="M6 9l6 6 6-6"/></svg>
      </button>
    </div>
    
    <div class="clini-chapter-collapse" hidden>
      <ul class="clini-block-list">
        <li class="clini-block-item">
          <a href="#stemi-ecg">
            <span>1.1 Tiêu chuẩn ECG & Dạng tương đương STEMI</span>

        </li>

</div>
```

## Pattern 3: Bedside Calculator Jaw & Bottom Drawer

*Khung tương tác bật lên từ đáy màn hình:* Không che khuất trang hiện tại, bác sĩ có thể tính liều thuốc hoặc tính điểm lâm sàng rồi đóng ngay.

```html
<!-- Floating Drawer Trigger Button -->
<button class="clini-btn clini-btn--cta-glow clini-floating-calc-btn" onclick="openDrawer('calc-gfr')">
  <span>⚡ Tính eGFR</span>
</button>

<!-- Bottom Drawer Container -->
<div id="calc-gfr" class="clini-drawer-jaw">
  <div class="clini-jaw-header">
    <div class="clini-jaw-title">
      <span>🧪</span>
      <span>Ước Tính Mức Lọc Cầu Thận (CKD-EPI 2021)</span>
    </div>
    <button class="clini-btn clini-btn--ghost clini-btn--sm" onclick="closeDrawer('calc-gfr')">✕</button>
  </div>
  <div class="clini-jaw-body">
    <div class="clini-form-row">
      <input type="number" class="clini-input" placeholder="Creatinine huyết thanh (mg/dL)">
      <input type="number" class="clini-input" placeholder="Tuổi">
    </div>
    <div class="clini-jaw-result">
      <span>Kết quả eGFR:</span>
      <strong class="clini-text-primary">82 mL/min/1.73m² (G2 - Giảm nhẹ)</strong>
    </div>
  </div>
</div>
```
