# Quy Tắc Đặt Tên File & Slug (File Naming Rules)

## 📌 Quy định Bắt buộc

1. **Tên file & Thư mục**:
   - Sử dụng **ALL LOWERCASE**, **kebab-case**, **ASCII thuần** (không dấu, không khoảng trắng, không ký tự đặc biệt).
   - ✅ `cap-nhat-ve-bao-giap-2026.html`
   - ❌ `Cập Nhật Bảo Giáp 2026.html` / `cap_nhat_bao_giap.html`

2. **Biến & Hàm trong JS**:
   - `camelCase` cho biến và hàm: `fetchGuidelineData`, `calculateSofaScore`, `activeTabId`.
   - `PascalCase` cho Class và Component: `ClinicalEngine`, `FlowchartViewer`.

3. **CSS Classes & IDs**:
   - `kebab-case` cho class và id trong HTML/CSS.
   - ✅ `.sec-card`, `#header-placeholder`, `.btn-primary-action`
   - ❌ `.secCard`, `#header_placeholder`
