Cung cấp 2 đoạn code JSON để nạp vào CSDL Tri thức Suy luận CDSS:
• Đoạn 1: Bổ sung triệu chứng vào file: `src/content/knowledge-vault/data/clinical-rules-symptoms.json` (nếu có triệu chứng mới).
