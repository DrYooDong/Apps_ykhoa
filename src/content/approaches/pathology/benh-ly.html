Tự động đồng bộ dữ liệu bệnh lý và lưu đồ kéo-thả lên dự án Supabase cá nhân. Dữ liệu sử dụng bảng: clinical_pathology

💡 Câu lệnh SQL tạo bảng mẫu trên Supabase 
create table clinical_pathology (
  id text primary key,
  name text not null,
  icd text,
  specialty text,
  description text,
  bookmarked boolean default false,
  flowchart jsonb,
  "createdAt" timestamp with time zone default timezone('utc'::text, now())
);
