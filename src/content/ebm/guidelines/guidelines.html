🌲
Forest Plot
Tự động nhận diện khi có HR / OR / RR và 95% CI
Cú pháp:
HR 0.75 (95% CI 0.65-0.86, p<0.001) OR 0.62 (95% CI 0.48-0.79) RR 1.24 (95% CI 1.08-1.43, p=0.002)
✅ Tự động màu xanh nếu có lợi (HR<1), đỏ nếu bất lợi (HR>1)
📊
Biểu đồ Cột (Column)
Bắt đầu bằng tiền tố COL: — so sánh tỷ lệ % giữa các nhóm
Cú pháp:
COL: Can thiệp: 3.7% | Giả dược: 5.9% COL: Tử vong TM: 3.7% | Suy tim: 2.7% | Đột quỵ: 1.2%
📌 Phân cách nhóm bằng | — Nhãn và giá trị phân cách bằng :
📉
Biểu đồ Ngang (HBAR)
Bắt đầu bằng HBAR: — trực quan hóa theo chiều ngang
Cú pháp:
HBAR: Đột quỵ: 1.2% | Suy tim: 2.7% | Tử vong: 3.7%
📌 Thích hợp khi có nhiều nhóm hơn 3 items
⚖️
So sánh 2 nhóm
Tự động nhận diện cú pháp X% vs Y%
Cú pháp:
3.7% vs 5.9% Can thiệp 12.5% vs Đối chứng 24.8%
✅ Tự động xanh = nhóm thấp hơn, đỏ = nhóm cao hơn
🍩
Vòng Donut / Tiến độ
Tự động nhận diện tỷ lệ phần trăm đơn lẻ
Cú pháp:
91% (63/69) Đạt mục tiêu HbA1c: 78%
📌 Hiển thị số bệnh nhân (n/N) nếu có

Subgroup Forest Plot (JSON)
Nhập JSON vào ô Subgroup JSON bên dưới — tự động vẽ Forest Plot đa hàng khi mở rộng chi tiết
Cú pháp (JSON):
{
  "Châu Á": "HR 0.82 (95% CI 0.64-1.04)",
  "Suy tim": "HR 0.65 (95% CI 0.50-0.85)",
  "CKD eGFR<45": "HR 0.58 (95% CI 0.42-0.81)"
}
✅ Hiển thị trong hàng mở rộng (click vào dòng bất kỳ)

☁️ Cấu hình Supabase

Đồng bộ dữ liệu tài liệu & nghiên cứu lên đám mây Supabase để đồng bộ hóa trên mọi thiết bị. Dữ liệu sẽ tự động lưu tạm thời tại LocalStorage khi ngoại tuyến.

💡 Câu lệnh SQL tạo bảng & Phân quyền RLS trên Supabase 
create table if not exists clinical_guidelines (
  id text primary key,
  title text not null,
  author text,
  drug text,
  "sourceType" text,
  specialty text,
  design text,
  intervention text,
  "primaryEndpoint" text,
  "keyResults" text,
  impact text,
  year integer,
  organization text,
  phase text,
  "sampleSize" integer,
  population text,
  summary text,
  "detailedConclusion" text,
  "fdaStatus" text,
  "sourceUrl" text,
  file text,
  "asianData" boolean,
  bookmarked boolean,
  icd10 text,
  subgroups text,
  parts text,
  "conditionKey" text,
  "createdAt" timestamp with time zone default timezone('utc'::text, now())
);

-- Phân quyền RLS truy cập cho role public/anon:
alter table clinical_guidelines enable row level security;
create policy "Allow anon select" on clinical_guidelines for select using (true);
create policy "Allow anon insert" on clinical_guidelines for insert with check (true);
create policy "Allow anon update" on clinical_guidelines for update using (true);
create policy "Allow anon delete" on clinical_guidelines for delete using (true);
